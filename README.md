## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Sketch Library** | Organize Sketchbook files by series, subject and date |
| **Brush Collections** | Track custom brush sets with style and technique notes |
| **Canvas Presets** | Save canvas size and resolution presets per output target |
| **Project Series** | Group related sketches into named series for portfolio tracking |
